# RW-01-Reaction-Wheel-Controller

## Project Overview
Development of a custom PCB-based, single-axis
reaction-wheel attitude control system.

## Project Objectives
- Model reaction-wheel dynamics
- Design a closed-loop attitude controller
- Develop a custom motor-control PCB
- Build and test a physical prototype
- Validate simulation against experimental results

## Technologies
- Python
- STM32 / Embedded C
- KiCad
- SolidWorks
- PID Control

## Project Status
Phase 1: Research and system requirements
